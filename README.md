🚀 Deployment (Vercel)This is a zero-build static site—no Node.js, npm, or bundler required.Go to vercel.com and sign in with GitHub.Click Add New → Project and import Jayesh2512/dopehloo-portfolio.Keep all framework/build settings as default and click Deploy.Activate Contact Form: Submit one test inquiry on your live Vercel URL, then open dopehloo@gmail.com and click the one-time Activate link from FormSubmit.Optional: Updating ContentAdd inline playback for Sutta: Open index.html, search for id: 'sutta', and paste the 11-character YouTube video ID into videoId: ''.Add new films: Append a new object to the PROJECTS array inside index.html.Built for Do Pehloo — Delhi, India.
